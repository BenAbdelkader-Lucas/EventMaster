# MEGA-SAE

EventMaster

Application desktop de gestion d'événements (marque blanche) développée en JavaFX dans le cadre du BUT Informatique à l'IUT2 (Université Grenoble Alpes).
Présentation

EventMaster centralise la création d'événements, le suivi des participants et la gestion financière. L'application intègre un système de modèles (templates) pour créer rapidement des événements récurrents, ainsi qu'un suivi budgétaire en temps réel.

Fonctionnalités

    Gestion d'événements : Création, édition et planification d'événements à partir de modèles réutilisables.

    Membres & Inscriptions : Suivi des participants, attribution des rôles et des accès.

    Suivi financier : Gestion des dépenses/recettes en temps réel et bilan budgétaire.

    Personnalisation : Thème et identité visuelle adaptables selon l'organisation.

technologie

    Java / JavaFX (FXML, CSS)

    IntelliJ IDEA / Git
